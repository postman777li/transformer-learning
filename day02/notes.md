# Day 2：从文字到向量——Embedding 与矩阵基础

> 主线：文字 → Token ID → Embedding 向量 → 线性变换。重点是分清每一步做什么，以及 shape 如何变化。

## 1. 从一句话理解 Token 和 Token ID

假设分词器把“我喜欢苹果”编码为：

```text
我喜欢苹果 → 我 / 喜欢 / 苹果 → [12, 35, 208]
```

- **Tokenizer（分词器）**：按照规则与词表，将文本编码成 ID 序列。
- **Token**：文本的基本处理单位，可以是词、子词、字符或字节片段。
- **Vocabulary（词表）**：Token 与 ID 的对应关系。
- **Token ID**：Token 的整数编号，用于索引。

同一句话也可能被切成“我 / 喜 / 欢 / 苹 / 果”，取决于分词器。**Token 不一定等于一个汉字或完整单词。**

ID 就像学号：1002 不代表比 1001 能力更强。同样，208 不代表“苹果”比“喜欢”更重要；编号本身不表达语义大小关系。

## 2. Embedding：给编号查一个向量

假设词表有 1000 个 Token，每个用 4 维向量表示，Embedding 就是一张 `[1000, 4]` 的可训练参数表。ID 208 对应取出 `E[208]`：

```text
[12, 35, 208] → 查表 → [
  [0.2,  0.7, -0.1,  0.5],   # 我
  [0.9,  0.1,  0.3, -0.4],   # 喜欢
  [0.6, -0.2,  0.8,  0.1]    # 苹果
]
```

这里的数值只是教学示例，维度也不一定有可命名的语义。

**Embedding 将离散 ID 映射为连续向量；基本操作是取参数表中对应的行，不是查表时重新计算词义。**

```math
E\in\mathbb{R}^{V\times C}
```

其中 $`V`$ 是词表大小，$`C`$ 是向量维度。

### 表从哪里来？没见过的词怎么办？

词表决定有多少行；Embedding 通常随机初始化，再随模型训练更新：

```text
文本语料 → 预测任务 → 计算损失 → 反向传播 → 更新 Embedding 等参数
```

| 情况 | 结果 |
|---|---|
| “苹”在词表中，但语料没有出现 | 仍有对应向量；如果没有获得有效训练，不保证有可靠语义 |
| “苹”不在词表中 | 根据分词器设计，拆成已知片段、回退到字节，或使用 `[UNK]` |

“没有出现就完全不更新”并非普遍规则，还可能受到输入输出权重共享等机制影响。关键是：**有合法向量，不等于学到了有用的表示。**

| 对象 | 负责什么 |
|---|---|
| Tokenizer / 词表 | 如何切分文本、分配什么 ID |
| Embedding 表 | 每个合法 ID 对应什么向量 |
| 训练语料 | 通过训练帮助向量和其他参数学到有用的信息 |

## 3. Shape：从 `[B,T]` 到 `[B,T,C]`

沿用现有代码：两句话，每句 3 个 Token，每个 Token 用 4 维向量表示。

```text
Token IDs：[[12, 35, 208], [51, 9, 300]]

[2, 3] → Embedding(1000, 4) → [2, 3, 4]
```

| 维度 | 含义 | 本例 |
|---|---|---:|
| B：Batch Size | 样本数量 | 2 |
| T：Sequence Length | 每条样本的 Token 位置数 | 3 |
| C：Embedding Dimension | 每个 Token 的向量维度 | 4 |

常见表示是：

```math
X\in\mathbb{R}^{B\times T\times C}
```

单句不带 Batch 维度时，`[3]` 个 ID 会变成 `[3,4]`；同一批句子长度不同时，通常需要 Padding 等方式整理。


### `.shape` 中有几个数，就是几阶张量

`[B,T,C]` 表示张量的形状，可理解为一个三维数组；三个数分别是三条轴的长度。例如：

```python
x = torch.tensor([
    [[1, 2, 3], [4, 5, 6]],       # 第 1 条样本：2 个 Token，各 3 个特征
    [[7, 8, 9], [10, 11, 12]]     # 第 2 条样本
])

print(x.shape)  # torch.Size([2, 2, 3])：B=2，T=2，C=3
print(x.ndim)   # 3：张量有 3 条轴
# x[0]       → 第 1 条样本，shape [2,3]
# x[0, 1]    → 该样本的第 2 个 Token：[4,5,6]，shape [3]
# x[0, 1, 2] → 这个 Token 的第 3 个特征：6，标量
```

**注意“几维向量”和“几维数组”的区别**：`[0.6,0.8,0.9,0.2]` 有 4 个分量，叫“四维向量”，但作为张量的 `shape=[4]`，只有一条轴，是一阶张量；写成 `[[0.6,0.8,0.9,0.2]]` 后 `shape=[1,4]`，才有两条轴。`shape` 记录的是各轴长度，不是数据本身。

## 4. 线性变换：用苹果例子理解特征重组

另设一个仅用于教学的苹果向量，假设它的四个分量有明确含义：

| 原特征 | 红色程度 | 圆形程度 | 甜度 | 硬度 |
|---|---:|---:|---:|---:|
| 数值 | 0.6 | 0.8 | 0.9 | 0.2 |

我们想将这 4 个特征组合成 3 个新特征：

| 新特征 | 组合规则 | 结果 |
|---|---|---:|
| 外观吸引力 | 红色 + 圆形 | 1.4 |
| 口感评分 | 甜度 − 硬度 | 0.7 |
| 综合评分 | 红色 + 甜度 | 1.5 |

这可以用一次矩阵乘法完成：

```math
xW= \begin{bmatrix}0.6&0.8&0.9&0.2\end{bmatrix} \begin{bmatrix} 1&0&1\\ 1&0&0\\ 0&1&1\\ 0&-1&0 \end{bmatrix} = \begin{bmatrix}1.4&0.7&1.5\end{bmatrix}
```

W 的 **4 行对应原来的 4 个特征，3 列对应新的 3 个特征**。输出的每个数，都由输入向量与 W 的对应列做点积得到。

```text
[红色, 圆形, 甜度, 硬度] → [外观吸引力, 口感评分, 综合评分]
shape [1,4] @ [4,3] → [1,3]
```

### 对应 PyTorch

```python
import torch
import torch.nn as nn

x = torch.tensor([[0.6, 0.8, 0.9, 0.2]])  # shape [1,4]
linear = nn.Linear(4, 3, bias=False)

# 教学中手动设定；真实训练时由模型学习
with torch.no_grad():
    linear.weight.copy_(torch.tensor([
        [1, 1, 0, 0],    # 红色 + 圆形
        [0, 0, 1, -1],   # 甜度 - 硬度
        [1, 0, 1, 0]     # 红色 + 甜度
    ], dtype=torch.float32))

y = linear(x)
print(y)  # tensor([[1.4000, 0.7000, 1.5000]])，shape [1,3]
```

数学上右乘的 W 是 `[4,3]`；PyTorch 的 `linear.weight` 存为 `[3,4]`，计算等价于 `x @ linear.weight.T`。这里关闭了偏置；默认的 `nn.Linear` 包含偏置，对应：

```math
y=xW+b
```

**Linear 改变的是特征表示，不是 Token 编号。** 对每个 Token 用同一套权重，只改变最后一维：

```text
[B,T,C] @ [C,D] → [B,T,D]
[16,256,512] → Linear(512,128) → [16,256,128]
```

本例的特征含义和组合规则是人为设定的；真实 Transformer 的每一维通常没有这么明确的人工含义，权重也通过训练学习。

## 5. 点积与矩阵乘法

先看两个向量：$`a=[1,2]`$、$`b=[2,3]`$。对应元素相乘再求和：

```math
a\cdot b=1\times2+2\times3=8
```

**点积的结果是标量。** 它可以表示匹配分数，但也受向量长度影响，不能直接把数值大小等同于语义相似度；比较方向时常用余弦相似度。

矩阵乘法则把多次“行与列的点积”组织起来：

```math
\begin{bmatrix}1&2\\3&4\end{bmatrix} \begin{bmatrix}5&6\\7&8\end{bmatrix} =\begin{bmatrix}19&22\\43&50\end{bmatrix}
```

例如左上角的 `19 = 1×5 + 2×7`，来自左矩阵第一行与右矩阵第一列。相乘时，左矩阵的列数必须等于右矩阵的行数。

## 7. 快速自测与总结

| 问题 | 答案 |
|---|---|
| 词表大小 50000，向量维度 768，Embedding 表多大？ | `[50000,768]` |
| ID 的 shape 是 `[16,256]`，Embedding 维度 512，输出多大？ | `[16,256,512]` |
| `[8,128,512]` 经过 `Linear(512,64)` 呢？ | `[8,128,64]` |
| Embedding 与 Linear 有什么区别？ | 前者根据整数 ID 查向量，后者将已有向量组合成新特征 |

记住这条主线：

```text
文字 → Tokenizer → IDs [B,T]
                    ↓ Embedding 查表
                 向量 [B,T,C]
                    ↓ Linear 变换特征
                 向量 [B,T,D]
```
